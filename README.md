# AI Trader — MVP V2

Protótipo web estático para validação de produto. Não executa ordens e usa dados demonstrativos.

## Publicar rapidamente
1. Crie uma conta no Vercel.
2. Crie um projeto novo e faça upload deste arquivo `index.html` (ou conecte um repositório GitHub).
3. Publique.
4. Depois conecte domínio próprio.

## Próxima fase técnica
- Next.js + TypeScript
- Supabase para autenticação/banco
- Provedor licenciado de dados de mercado
- Motor quantitativo separado do LLM
- API segura para IA
- Stripe/Mercado Pago para assinaturas
- Logs, limites e controles de risco
- Revisão jurídica/regulatória antes de recomendações individualizadas ou execução real
